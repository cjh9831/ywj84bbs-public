# 澳门卦象数据库

## 1. 目的

本目录保存澳门各期实际数据库中的起卦卦象资料。

澳门起卦体系不在本 README 中预先限定。

原则：

> 数据库实际存在什么起卦资料，就保存什么起卦资料。

---

## 2. 数据来源原则

所有澳门卦象以实际数据库和原始资料为准。

禁止：

* 凭记忆补造
* 自行推测不存在的起卦体系
* 删除历史卦象
* 用分析结果覆盖原始卦象
* 将不同来源合并成无法追溯的数据

---

## 3. 建议目录

初始：

```text
hexagrams/
└── README.md
```

发现实际起卦体系后，再按照实际资料建立对应目录。

例如：

```text
hexagrams/
├── README.md
├── source_A/
├── source_B/
└── source_C/
```

这里的名称必须以实际数据库资料为准。

---

## 4. 单期文件

建议：

```text
MC-YYYY-NNN_<source>.json
```

例如：

```text
MC-2026-235_source_A.json
```

具体 source 名称按照实际资料填写。

---

## 5. 单个卦象记录

建议保存：

| 字段                   | 说明       |
| -------------------- | -------- |
| draw_id              | 对应期号 ID  |
| market               | macau    |
| source               | 起卦来源     |
| stroke               | 起卦笔画，如适用 |
| divination_value     | 起卦数字/原始值 |
| hexagram_name        | 卦名       |
| upper_trigram        | 上卦       |
| lower_trigram        | 下卦       |
| moving_line          | 动爻，如有    |
| changed_hexagram     | 变卦，如有    |
| original_description | 原始描述     |
| source_file          | 来源文件     |
| verified             | 核验状态     |
| version              | 数据版本     |

---

## 6. 多来源独立保存

如果同一期存在多个起卦来源：

```text
source_A
source_B
source_C
```

必须分别保存。

不得直接合并成一个没有来源标记的卦象。

---

## 7. 原始资料与分析资料分离

```text
RAW 原始卦象
      ↓
结构化卦象
      ↓
分析
```

以下属于后续派生结果：

* 卦象解释
* 权重
* 号码映射
* 候选号码
* 28码
* 24码
* 20码
* 16码
* 12码
* 8码

不得覆盖原始卦象。

---

## 8. 版本原则

同一期同一来源出现新版本：

```text
旧版本
+
新版本
```

全部保留。

例如：

```text
MC-2026-235_source_A_v1.json
MC-2026-235_source_A_v2.json
```

---

## 9. 核验状态

允许：

```text
unverified
verified
needs_review
```

未经核验的资料不得标记为 verified。

---

## 10. 新起卦体系

如果未来数据库出现新的澳门起卦体系：

1. 新增 source。
2. 保存原始资料。
3. 建立对应结构。
4. 保留来源文件。
5. 记录版本。
6. 经过核验后再纳入分析。

不得为了保持结构整齐而删除旧资料。

---

## 11. 数据完整性检查

每期检查：

* [ ] draw_id 正确
* [ ] 期号正确
* [ ] source 明确
* [ ] 起卦数字/笔画如有则保存
* [ ] 卦名如有则保存
* [ ] 上卦如有则保存
* [ ] 下卦如有则保存
* [ ] 动爻如有则保存
* [ ] 变卦如有则保存
* [ ] 原始描述保存
* [ ] source_file 保存
* [ ] 核验状态明确
* [ ] version 明确

---

## 12. 特别规定

澳门起卦体系：

**以实际数据库为唯一依据。**

Schema 不预设具体体系。

以后出现新的起卦资料时：

> 追加，不覆盖。

---

## 13. 与分析层的关系

```text
澳门实际起卦资料
        ↓
      卦象
        ↓
     八肖参考
        ↓
     号码映射
        ↓
     候选号码
        ↓
28 → 24 → 20 → 16 → 12 → 8
        ↓
     实际结果验证
```
