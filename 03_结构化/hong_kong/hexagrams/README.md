# 香港卦象数据库

## 1. 目的

本目录保存香港各期的原始及结构化卦象资料。

香港目前确定的主要起卦资料：

* 21画
* 29画
* 42画

三套资料必须分别保存，不得合并后覆盖来源。

---

## 2. 数据来源原则

卦象资料以实际数据库和原始资料为准。

禁止：

* 凭记忆补造卦象
* 用推测资料代替原始资料
* 删除旧卦象
* 用分析结果覆盖原始卦象
* 将不同起卦来源合并成无法追溯的数据

---

## 3. 建议目录

```text
hexagrams/
├── README.md
├── 21_strokes/
├── 29_strokes/
└── 42_strokes/
```

---

## 4. 单期文件命名

建议：

```text
HK-YYYY-NNN_21_strokes.json
HK-YYYY-NNN_29_strokes.json
HK-YYYY-NNN_42_strokes.json
```

例如：

```text
HK-2026-092_21_strokes.json
HK-2026-092_29_strokes.json
HK-2026-092_42_strokes.json
```

---

## 5. 单个卦象记录

每条卦象资料建议保存：

| 字段                   | 说明        |
| -------------------- | --------- |
| draw_id              | 对应期号 ID   |
| market               | hong_kong |
| source               | 起卦来源      |
| stroke               | 起卦笔画      |
| divination_value     | 起卦数字/原始值  |
| hexagram_name        | 卦名        |
| upper_trigram        | 上卦        |
| lower_trigram        | 下卦        |
| moving_line          | 动爻，如有     |
| changed_hexagram     | 变卦，如有     |
| original_description | 原始描述      |
| source_file          | 来源文件      |
| verified             | 核验状态      |
| version              | 数据版本      |

---

## 6. 三套卦象独立原则

### 21画

只保存 21画来源资料。

### 29画

只保存 29画来源资料。

### 42画

只保存 42画来源资料。

三套资料可以共同参与后续分析，但不能因为分析而互相覆盖。

---

## 7. 原始资料与分析资料分离

```text
RAW 原始卦象
      ↓
结构化卦象
      ↓
分析
```

卦象本身属于基础资料。

后续分析产生的：

* 卦象解释
* 权重
* 号码映射
* 候选号码
* 分层号码

不得写回原始卦象文件。

---

## 8. 版本原则

如果同一期同一来源出现新的资料：

```text
旧版本
+
新版本
```

全部保留。

例如：

```text
HK-2026-092_21_strokes_v1.json
HK-2026-092_21_strokes_v2.json
```

不得直接删除 v1。

---

## 9. 核验状态

允许：

```text
unverified
verified
needs_review
```

### unverified

已经保存，但尚未完成核验。

### verified

已经与可靠来源完成核验。

### needs_review

发现冲突、缺失或格式异常，需要人工检查。

---

## 10. 新资料规则

以后如果数据库出现新的香港起卦来源：

1. 不删除旧来源。
2. 新增独立来源。
3. 记录 source。
4. 记录 source_file。
5. 记录 version。
6. 保留原始资料。
7. 再决定是否纳入分析。

---

---

## 12. 特别规定

香港目前确定：

**21画 / 29画 / 42画**

这是数据库资料结构，不代表以后不会增加新的起卦来源。

任何新增来源都必须采用“追加”方式，不得覆盖现有资料。

---

## 13. 与分析层的关系

卦象数据库只提供上游资料：

```text
21画 ─┐
29画 ─┼→ 卦象资料
42画 ─┘
        ↓
     八肖参考
        ↓
     号码映射
        ↓
     候选号码
        ↓
28 → 24 → 20 → 16 → 12 → 8
```

实际开奖结果属于验证层，不得反向修改卦象资料。
